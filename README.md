## Щоденник розробника

### 02.10.2026 — Юніт 1: персонаж і рух

Зробила сцену MainScene, персонажа з набору Ducko і скрипт PlayerController. Підлогу намалювала тайлмапом з двох плиток (Rule Tile) через власну палітру Game Palette. Керування зробила через Input Action: стрілки й WASD.
Найдовше не могла перетягнути спрайт у сцену: шукала його не в тій теці, а спочатку взяла не той спрайт (DuckoHitDown замість DuckoIdleDown1). Ще скрипт випадково створила всередині теки Art, довелося переносити в _2DAdventureGame/Scripts. Качечка не рухалась, бо метод Update у новому скрипті порожній, а код я не вписала. Visual Studio показував «несовместимо», бо не був встановлений компонент для Unity.
Зрозуміла, що Update викликається щокадру, а Time.deltaTime робить рух незалежним від частоти кадрів: перевірила на 10 кадрах за секунду, і швидкість лишилась тією самою, тільки рух став ривками. Також зрозуміла, чому плитки мали щілини: потрібен Pixels Per Unit = 64, а підлогу треба класти під персонажа через Order in Layer = -10.
